# Proyecto Entornos de Desarrollo: Gestión de Pedidos
# 1. Resumen del proyecto
En este proyecto he creado un sistema de gestión de pedidos, vendiendo tanto productos físicos como digitales, también 
he creado clientes y  también les he asignado un pedido a cada uno, en los pedidos le he agregado tanto productos digitales 
como físicos y he hecho el cálculo total a pagar.

# Características principales: #
· Creacion de modelos para clientes, productos y pedidos.
· Tiene un soporte para productos digitales con tamaño de descarga y licencia y productos físicos con coste de envío.
· También calcula automático del precio final de cada producto y del pedido completo.
· Muestra un resumen completo de pedidos.

# 2. Instrucciones de ejecución
Para ver el proyecto:
Abres el proyecto en visual studio o otro editor
Ejecutar la clase Main.java desde Run Java o el icono de ejecutar.

Para ver el diagrama uml inicial:
Entras en output\proyecto_entornos.puml
Después coges y clicas en el buscador y pones >PlantUML: Preview Current Diagram

Para ver el automatico haces lo mismo pero con el fichero output\proyecto_entornos_AUTOMATICO.puml
